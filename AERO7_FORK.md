# Aero7 File Explorer

This is the independent Aero7 file-manager fork. It was created from the
current modified `aero7-dolphin` working tree on 2026-08-17, including its
uncommitted Aero7 shell, library, common-dialog, Computer-view, and file
operation work. Generated build output was deliberately excluded.

The installed application identity is:

- binary: `aero7-file-explorer`
- desktop id: `org.aero7.FileExplorer`
- visible name: `File Explorer`

Historical Dolphin class and library names are retained internally where
renaming them would add compatibility risk without changing the visible Aero7
experience. The old `aero7-dolphin` working tree is not modified by this fork.
