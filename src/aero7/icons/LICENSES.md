# Aero7 File Explorer icon provenance

The application, view-action, and command-chrome PNG files under this directory
are selected from `aerothemeplasma-icons` commit
`96950b8028a5d960cb683280fe5f1d9e33e6b8a2`, the same revision pinned by the
Aero7 Pacman repository. Pixels are unmodified; selected files are renamed only
to provide stable Aero7 resource and launcher identities.
