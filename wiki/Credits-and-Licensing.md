# Credits and Licensing

## Aero7 File Explorer

Aero7 File Explorer is developed as the complete file-management application
for the Aero7 desktop. Aero7-specific work includes its public application
identity, Windows 7-inspired Explorer surface, shell integration, Library and
Computer models, common dialogs, properties, local file-operation workflows,
tests, packaging, and documentation.

## KDE Dolphin upstream

The project is a maintained fork of
[`KDE/dolphin`](https://github.com/KDE/dolphin) and retains substantial KDE and
Dolphin implementation heritage. The GitHub repository records KDE Dolphin as
its parent and source. Historical upstream copyright notices, authorship, and
license files remain applicable.

## License files

The reviewed Aero7 package declares `GPL-2.0-or-later` and installs the source
tree's `COPYING` and `COPYING.DOC` files under the package license directory.
Individual source files and bundled components may carry their own compatible
notices. The repository license files and file headers are authoritative; this
Wiki is a summary, not a replacement for them.

Do not remove or rewrite upstream attribution when adopting Dolphin changes.
New third-party code or assets must include a compatible license and clear
source information before entering the package or release image.
